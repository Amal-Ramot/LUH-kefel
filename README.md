# לוח הכפל בכיף ✖️🦒🐙

אפליקציית **Next.js + React** ללימוד לוח הכפל לילדים: דמויות מצוירות, סיפורים, טריקים ומשחקים.
האתר נבנה כאתר סטטי ומתפרסם אוטומטית ב-**GitHub Pages**.

## שיטת הלימוד – 6 צעדים לזיכרון

1. **רואים** – כל תרגיל מוצג כמערך נקודות (7 × 8 = 7 שורות של 8), כך שהילד מבין מה זה כפל.
2. **חבר לכל מספר** – כל מספר מקבל דמות שמזכירה אותו: גילי הג׳ירפה (1), ברבורה (2), תלתן (3 עלים), בובי הכלב (4 רגליים), כוכבית (5 קצוות), מושית החיפושית (6 רגליים), קשתית (7 צבעים), תמנונה (8 זרועות), מיצי החתולה (9 נשמות), רובו הרובוט (10 אצבעות).
3. **טריק לכל לוח** – כפול 2 = חיבור כפול, כפול 4 = כפול-כפול, כפול 5 = חצי מ-10, טריק האצבעות של 9 ועוד.
4. **חרוזים וסיפורים** לתרגילים הקשים: ״5-6-7-8 → 56 = 7 × 8״, ״שש כפול שמונה – ארבעים ושמונה״.
5. **קסם ההחלפה** – 3 × 7 = 7 × 3, ולכן נשארים רק 21 תרגילים ״קשים״ באמת.
6. **חזרה מרווחת (שיטת לייטנר)** – תרגיל שטועים בו חוזר הרבה, ותרגיל שכבר יודעים חוזר פחות (🥚 → 🐣 → 🐥 → 🦅 → ⭐).

## הדפים

| דף | מה יש בו |
|---|---|
| `/` | דף הבית: הכרת הדמויות והשיטה |
| `/learn` | בחירת לוח לפי סדר מומלץ (מהקל לקשה) עם כוכבים והתקדמות |
| `/learn/[1-10]` | לימוד לוח: דמות, טריק, קפיצות על ציר המספרים, תרגילים עם ציור וסיפור, ובוחן כוכבים |
| `/table` | לוח הכפל האינטראקטיבי: מצב ״קסם ההחלפה״ ומצב ״מה אני כבר יודע/ת״ |
| `/practice` | תרגול חכם בחזרה מרווחת עם מקלדת מספרים |
| `/game` | ״מירוץ לירח״: 60 שניות, רצפים ונקודות כפולות |
| `/memory` | משחק זיכרון: מתאימים קלף תרגיל לקלף התשובה שלו, ב-3 רמות, עם שיא מהלכים |
| `/progress` | אלבום מדבקות, סטטיסטיקות ואיפוס |

ההתקדמות נשמרת ב-`localStorage` של הדפדפן. התשובות מוקלדות מהמקלדת (בטלפון נפתחת מקלדת מספרים), ו-Enter בודק.

### דמויות
איורי התלת-ממד של הדמויות הם [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (רישיון MIT), ונמצאים ב-`public/characters/1.png`–`10.png`. האנימציות (נשימה, ריחוף, קפיצה, שמחה וניצוצות) נעשות ב-CSS.

### קול
ההקראה היא קול נשי של Google Translate, מוקלט מראש לקובצי mp3 ב-`public/audio` (כל 100 התרגילים וכל המספרים של הקפיצות). אם קובץ לא נטען, האתר עובר לקול העברי של הדפדפן.
כדי להקליט מחדש (מדלג על קבצים קיימים):

```bash
node scripts/generate-audio.mjs
```

## פיתוח מקומי

```bash
npm install
npm run dev
```

## פרסום ב-GitHub Pages

1. ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. כל push ל-`main` מפעיל את `.github/workflows/deploy.yml`, שבונה את האתר (`output: "export"`) ומפרסם את תיקיית `out`.
3. ה-`basePath` (למשל `/LUH-kefel`) נקבע אוטומטית מתוך `actions/configure-pages`.

בנייה מקומית עם נתיב בסיס:

```bash
NEXT_PUBLIC_BASE_PATH=/LUH-kefel npm run build
```
